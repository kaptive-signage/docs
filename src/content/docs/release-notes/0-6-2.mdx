## Features

- New power on schedule feature to automatically control the display's power state based on a schedule. This feature allows users to set specific times for the display to turn on or off, enhancing energy efficiency and convenience.
- New asset library feature to manage media assets more effectively. Users can now reuse existing assets across multiple projects, streamlining the content creation process and ensuring consistency in branding and messaging.
- External emergency alert triggers. Triggers from external systems can now be integrated to display emergency alerts on the screen, improving safety and communication during critical situations.
