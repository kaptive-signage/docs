## Editor improvements

- **[Zoomable canvas](/guides/editor/zoom-project-canvas/)**: Zoom into your canvas for pixel-perfect precision while you build.
- **Video duration indicator**: See a video's length at a glance with a visual duration indicator.
- **Unreachable page warnings**: The editor now flags pages with no way in, so you never forget a transition or a button again.
- **[Element rotation](/guides/editor/element-rotation/)**: Rotate any element for more layout freedom.
- **Improved snapping**: Sharper alignment snapping makes clean, professional layouts effortless.
- **[PDF timed page rotation](/guides/editor/pdf-page-rotation/)**: Automatically scroll through PDF pages at an interval you set.
- **Animated illustrations (early access)**: Bring your content to life with customizable animated illustrations (`.lottie`). More to follow.

## Features

- **[Templates](/guides/editor/templates/)**: Launch new projects in seconds. Start from a ready-made template, swap the color palette, and stand out instantly.
- **[Public links & HTML embedding](/guides/editor/public-sharing/)**: Share a project with a public link or embed it in your website for interactive content on the web.
- **[PDF export](/guides/editor/pdf-export/)**: Export any project to PDF.
- **[Custom fonts](/guides/editor/custom-fonts/)**: Import your own fonts once and use them across every project to stay true to your brand.
