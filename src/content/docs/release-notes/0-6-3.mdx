## Features

- Auto return to home page after a period of inactivity. This feature allows users to set a specific time for the display to automatically return to the home page, enhancing user experience and ensuring that important content is always visible.

- Multi-page selection for bulk actions. Users can now select multiple pages at once to perform bulk actions, streamlining the content management process and saving time.
