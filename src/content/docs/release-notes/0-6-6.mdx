## Features

- [Playlists](/getting-started/playlists/): play several projects one after another, schedule them like a project, and publish or revert changes separately.

- Custom widgets: upload your own widgets and place them in any project. Uploading a new version updates every screen within seconds.

- [Improved project assignment](/getting-started/assign/): one dialog to manage a project's public link, the players it's the default on, its playlists and its schedule.

- Scheduling: switch between week and day view, see the schedule read-only on mobile, and revert unpublished changes.

- Projects overview: tiles show tags you can edit and mark public projects and projects with unpublished changes. You can also filter by these.

- Shapes: a new parallelogram shape, and double-click a shape to fit it.

- Transfer workspace ownership to another member.

- Light, dark or system theme.

## Improvements & fixes

- Backend bug fixes and performance improvements.
- Various UI improvements.
