## Features

- Redesigned scheduling: one main schedule per workspace, a Publish button to push changes to your players, faster editing right on the calendar, and start and end scripts for each entry.

- Command scripts for alerts: build the commands sent to displays (power, input, wait, RS232) from drag-and-drop blocks, and save them as reusable custom scripts.

- Button actions: buttons can go to another page or close the project.

- Style part of a text: apply styling to selected words inside a text element.
 
- Replace media from your library: swap an image, video or PDF for a file that's already in your library.

- Workspace timezone: set a default timezone for your workspace.

## Improvements & fixes

- Backend bug fixes and performance improvements.
- The media library is simpler, and there are various small fixes.
