## The Kaptive Player does not boot

<steps>
    1. Check the power connection and ensure the Player is properly plugged in.
    2. Verify that the power outlet is working by testing it with another device.
    3. Try a different power cable if available.
    4. If the Player still does not boot, contact Kaptive Support for further assistance.
</steps>

## The Kaptive Player is not connecting to the internet

<steps>
    1. Check the network connection and ensure the Player is properly connected to the internet.
    2. Verify that the Ethernet or Wi-Fi network is working by testing it with another device.
    3. Restart the Player and try connecting to the Wi-Fi network again.
    4. If the Player still cannot connect to the internet, contact Kaptive Support for further assistance.
</steps>
