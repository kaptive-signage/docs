Importa i tuoi font nel workspace e usali in qualsiasi progetto, così i tuoi contenuti rispecchiano sempre l'identità del tuo brand. Apri le impostazioni dei font del workspace e carica i tuoi file di font. Una volta importati, i tuoi font personalizzati appaiono accanto a quelli integrati nel selettore di font dell'editor, pronti per essere usati in ogni progetto del workspace.
