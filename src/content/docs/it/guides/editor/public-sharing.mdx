Pubblica qualsiasi progetto sul web per condividerlo oltre i tuoi schermi. Apri le opzioni di condivisione del tuo progetto, poi attiva l'accesso pubblico per generare un link pubblico che chiunque può aprire nel browser. Puoi anche copiare il codice di incorporamento per inserire il progetto direttamente nel tuo sito web come iframe interattivo. Entrambi restano sincronizzati con il tuo progetto, così ogni modifica che pubblichi appare istantaneamente ovunque sia condiviso.
