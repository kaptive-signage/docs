Qualsiasi elemento di contenuto può essere ruotato nell'editor per una maggiore libertà di layout e creatività. Per ruotare un elemento, selezionalo e usa il campo di rotazione nel pannello delle proprietà dell'elemento. Puoi inserire un angolo di rotazione specifico o trascinare il campo di rotazione per ruotare l'elemento liberamente.
