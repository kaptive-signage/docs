## Funktionen

- Überarbeitete Planung: ein Haupt-Schedule pro Workspace, eine Publish-Schaltfläche, um Änderungen an Ihre Players zu übertragen, schnelleres Bearbeiten direkt im Kalender sowie Start- und End-Skripte für jeden Eintrag.

- Befehlsskripte für Alarme: Stellen Sie die an Displays gesendeten Befehle (Ein/Aus, Eingang, Warten, RS232) aus Drag-and-Drop-Blöcken zusammen und speichern Sie sie als wiederverwendbare eigene Skripte.

- Button-Aktionen: Buttons können zu einer anderen Seite wechseln oder das Projekt schließen.

- Teile eines Textes formatieren: Wenden Sie Formatierungen auf ausgewählte Wörter in einem Textelement an.

- Medien aus Ihrer Bibliothek ersetzen: Tauschen Sie ein Bild, Video oder PDF gegen eine Datei aus, die sich bereits in Ihrer Bibliothek befindet.

- Workspace-Zeitzone: Legen Sie eine Standard-Zeitzone für Ihren Workspace fest.

## Verbesserungen & Fehlerbehebungen

- Fehlerbehebungen im Backend und Leistungsverbesserungen.
- Die Medienbibliothek ist einfacher geworden, dazu kommen verschiedene kleine Korrekturen.
