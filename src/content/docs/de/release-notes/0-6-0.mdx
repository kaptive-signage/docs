## Editor-Verbesserungen

- **[Zoombare Arbeitsfläche](/de/guides/editor/zoom-project-canvas/)**: Zoomen Sie in Ihre Arbeitsfläche für pixelgenaue Präzision beim Gestalten.
- **Video-Daueranzeige**: Erkennen Sie die Länge eines Videos auf einen Blick dank einer visuellen Daueranzeige.
- **Hinweis auf nicht erreichbare Seiten**: Der Editor weist jetzt auf Seiten ohne Zugang hin, so vergessen Sie nie wieder einen Übergang oder einen Button.
- **[Element-Rotation](/de/guides/editor/element-rotation/)**: Drehen Sie jedes Element für mehr Gestaltungsfreiheit.
- **Verbessertes Einrasten**: Präziseres Ausrichten sorgt mühelos für saubere, professionelle Layouts.
- **[Zeitgesteuerter PDF-Seitenwechsel](/de/guides/editor/pdf-page-rotation/)**: Blättern Sie automatisch im von Ihnen festgelegten Intervall durch PDF-Seiten.
- **Animierte Illustrationen (Early Access)**: Erwecken Sie Ihre Inhalte mit anpassbaren animierten Illustrationen (`.lottie`) zum Leben. Weitere folgen.

## Funktionen

- **[Vorlagen](/de/guides/editor/templates/)**: Erstellen Sie neue Projekte in Sekunden. Starten Sie mit einer fertigen Vorlage, passen Sie die Farbpalette an und heben Sie sich sofort ab.
- **[Öffentliche Links & HTML-Einbettung](/de/guides/editor/public-sharing/)**: Teilen Sie ein Projekt per öffentlichem Link oder betten Sie es in Ihre Website ein, für interaktive Inhalte im Web.
- **[PDF-Export](/de/guides/editor/pdf-export/)**: Exportieren Sie jedes Projekt als PDF.
- **[Eigene Schriftarten](/de/guides/editor/custom-fonts/)**: Importieren Sie Ihre eigenen Schriftarten einmal und nutzen Sie sie in jedem Projekt, treu Ihrer Marke.
