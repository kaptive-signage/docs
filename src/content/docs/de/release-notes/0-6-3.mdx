## Funktionen

- Automatische Rückkehr zur Startseite nach einer Zeit der Inaktivität. Sie können festlegen, nach welcher Zeit das Display automatisch zur Startseite zurückkehrt. Das verbessert das Benutzererlebnis und stellt sicher, dass wichtige Inhalte immer sichtbar sind.

- Mehrfachauswahl von Seiten für Sammelaktionen. Sie können jetzt mehrere Seiten gleichzeitig auswählen und Aktionen auf alle anwenden, was die Verwaltung von Inhalten vereinfacht und Zeit spart.
