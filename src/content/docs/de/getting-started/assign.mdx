## So funktioniert die Zuweisung Ihres Projekts an einen Kaptive Player

Sobald Sie Ihr Projekt erstellt haben, möchten Sie es Ihren Kaptive Players zuweisen. Dieser Schritt wird als Zuweisung bezeichnet.

Wenn Sie auf die Schaltfläche `Assign` oben rechts im Kaptive Editor klicken, können Sie auswählen, welchen Players Sie Ihr Projekt zuweisen möchten. Nachdem Sie die Players ausgewählt haben, klicken Sie auf `Assign`, um die Wiedergabe auf den Kaptive Players zu starten.

![Projekt den Players zuweisen](../../../../assets/getting-started/assign/assign-project.png)

Das zugewiesene Projekt wird sofort auf den ausgewählten Kaptive Players wiedergegeben. Sie können dasselbe Projekt mehreren Players zuweisen. Das zugewiesene Projekt ist der Standardinhalt, der auf den zugewiesenen Players abgespielt wird.

Erfahren Sie im nächsten Kapitel, wie die Planung von Projekten auf Kaptive funktioniert.

## Aktualisierungen Ihres Projekts veröffentlichen

Manchmal möchten Sie Ihr Projekt aktualisieren, nachdem Sie es Ihren Players zugewiesen haben. Zum Beispiel könnten Sie Inhalte ändern oder einen Tippfehler korrigieren wollen. In diesem Fall klicken Sie einfach auf die orangefarbene Schaltfläche `Publish` direkt neben der Schaltfläche `Assign` im Kaptive Editor. Dadurch wird die neueste Version Ihres Projekts auf allen Players veröffentlicht, die ihm derzeit zugewiesen sind.

Dies ist besonders wichtig, wenn Sie Ihr Projekt in einem Schedule geplant haben. Damit der Schedule die neueste Version Ihres Projekts anzeigt, müssen Sie die Änderungen nach der Bearbeitung Ihres Projekts veröffentlichen. Erfahren Sie mehr über die Planung im nächsten Kapitel.
