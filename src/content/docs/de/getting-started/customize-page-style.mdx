## Über Seitenstile

Jede Seite hat einen Seitenstil, der ihr Standardaussehen definiert, einschließlich Hintergrundfarbe, Schriftarten und anderer Stileinstellungen. Sie können den Seitenstil anpassen, damit er zu Ihrem Branding oder Ihren Designvorlieben passt. Sie können auch verschiedene Seitenstile für jede Seite Ihres Projekts erstellen.

![Seitenstil anpassen](../../../../assets/getting-started/page-style/customize-page-style.png)

Speichern Sie den Seitenstil nach der Anpassung, um ihn auf Ihr Projekt anzuwenden.
