## Was ist Interaktivität?

Der Kaptive Editor ermöglicht die Erstellung vollständig touchfähiger Oberflächen, die für die physische Interaktion mit Bildschirmen konzipiert sind. Sie können Schaltflächen, 3D-Modelle, scrollbare PDFs und viele weitere Elemente und Widgets hinzufügen, mit denen Sie eine vollständige Anwendung für Museen, Gebäudeorientierung, Informationsbildschirme oder Bestellterminals erstellen können.

Anstatt eine vollständige Webanwendung oder native Anwendung für einen Touchscreen entwickeln zu müssen, können Sie alles mit Kaptive umsetzen.

![Schaltflächen für Interaktivität hinzufügen](../../../../assets/getting-started/interactivity/kaptive_editor.png)

## Schaltflächen hinzufügen

In der Werkzeugleiste des Kaptive Editors können Sie eine Schaltfläche zu Ihrem Projekt hinzufügen. In den Eigenschaften einer Schaltfläche können Sie auswählen, auf welche Seite verlinkt werden soll. So können Sie vollständige Anwendungen mit mehreren Seiten, Übergängen und Interaktionen erstellen.

Vergessen Sie nicht, auf Detailseiten Zurück-Schaltflächen hinzuzufügen, um die korrekte Navigation durch Ihre gesamte Anwendung zu ermöglichen.

## Transparenz oder Bilder zu Schaltflächen-Hintergründen hinzufügen

Für fortgeschrittenere interaktive Anwendungen können Sie Schaltflächen transparent machen oder Hintergrundbilder hinzufügen. So können Sie einfach Bento-Boxen, Listen oder klickbare Schemata, Pläne und Karten erstellen.
