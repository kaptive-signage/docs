## Ihren Player-Typ wählen

Sie können Kaptive-Inhalte entweder mit einem Kaptive Player oder mit Kaptive Web abspielen, das in jedem Browser läuft. Der Kaptive Player bietet eine höhere Zuverlässigkeit und Sicherheit. Einige Funktionen, wie Player-Screenshots, sind auf Kaptive Web nicht verfügbar.

Wir empfehlen die Verwendung eines Kaptive Players für kommerzielle Einsätze, während Kaptive Web für Tests und kleinere Anwendungsfälle geeignet ist.

Kaptive Web ist unter [https://player.kaptive.app](https://player.kaptive.app) erreichbar.

## Einen Player mit Ihrem Konto verbinden

Beim ersten Start eines Kaptive Players oder beim Zugriff auf Kaptive Web werden Sie aufgefordert, den Player mit Ihrem Kaptive-Konto zu verbinden.

![Player-Verbindungsbildschirm](../../../../assets/getting-started/connect-player/code.png)

Um den Player mit Ihrem Konto zu verbinden:

<Steps>
    1. Scannen Sie den QR-Code oder geben Sie den Code manuell auf [https://kaptive.app/verify](https://kaptive.app/verify) ein.
    2. Wählen Sie einen Namen für Ihren Player, um ihn in Ihrem Konto zu identifizieren.
    3. Wählen Sie den Workspace aus, in den Sie den Player hinzufügen möchten.
    4. Klicken Sie auf `Verify Device`.
 </Steps>

Sobald der Player verbunden ist, erscheint er in Ihrem Konto unter dem ausgewählten Workspace, und Sie können mit der Veröffentlichung von Inhalten beginnen.
