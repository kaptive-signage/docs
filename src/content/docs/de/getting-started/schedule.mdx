## So funktioniert die Planung auf Kaptive Players

Sie haben wahrscheinlich bereits das Kapitel über die Projektzuweisung gelesen. Die Planung ist die andere Möglichkeit, Inhalte auf Ihren Kaptive Players anzuzeigen. Anstatt einem Player ein einzelnes Projekt zuzuweisen, können Sie mehrere Projekte in einem Schedule planen. Ein Schedule ist eine Sammlung von Projekten, die zu bestimmten Zeiten auf einem Player angezeigt werden.

Beim Erstellen eines Schedules können Sie auswählen, welche Projekte im Schedule enthalten sein sollen und wann sie auf den zugewiesenen Players angezeigt werden sollen.

![Projekte planen](../../../../assets/getting-started/schedule/schedule.png)

Wenn Sie auf ein Projekt im Schedule klicken, können Sie den Zeitraum auswählen, in dem das Projekt angezeigt werden soll, und das Wiederholungsintervall konfigurieren. Die Wiederholung kann nur eingestellt werden, wenn sich keine anderen geplanten Projekte in der Zukunft überschneiden.

![Schedule bearbeiten](../../../../assets/getting-started/schedule/edit-schedule.png)

Sie können einem Schedule beliebig viele Projekte hinzufügen, aber sie dürfen sich zeitlich nicht überschneiden.

## Einen Schedule einem Player zuweisen

Nachdem Sie einen Schedule erstellt haben, können Sie ihn einem Player zuweisen, indem Sie auf die Schaltfläche `Assign` im Schedule-Editor klicken. Wenn ein Schedule einem Player zugewiesen ist, zeigt der Player die Projekte im Schedule gemäß den definierten Zeiträumen und Wiederholungseinstellungen an.

Wenn ein Schedule einem Player zugewiesen ist, aber zum aktuellen Zeitpunkt kein Projekt geplant ist, zeigt der Player das zugewiesene Standardprojekt an. So können Sie Ersatzinhalte bereitstellen, wenn keine geplanten Projekte aktiv sind. Der Standardinhalt wird konfiguriert, indem dem Player ein Projekt zugewiesen wird.

![Schedule-Zuweisung](../../../../assets/getting-started/schedule/assign-schedule.png)

## Aktualisierungen Ihres Schedules veröffentlichen

Wenn Sie Änderungen an einem Schedule vornehmen, müssen Sie die Änderungen veröffentlichen, damit sie auf den zugewiesenen Players wirksam werden. Um die Änderungen zu veröffentlichen, klicken Sie einfach auf die orangefarbene Schaltfläche `Publish` im Schedule-Editor. Dadurch wird der Schedule auf allen Players aktualisiert, denen dieser Schedule derzeit zugewiesen ist.
