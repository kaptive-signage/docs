Jedes Inhaltselement kann im Editor gedreht werden, für mehr Gestaltungsfreiheit und Kreativität. Um ein Element zu drehen, wählen Sie es aus und verwenden Sie das Rotationsfeld im Eigenschaftenbereich des Elements. Sie können einen bestimmten Drehwinkel eingeben oder das Rotationsfeld ziehen, um das Element frei zu drehen.
