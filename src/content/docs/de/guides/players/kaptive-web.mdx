Kaptive Web ermöglicht es Ihnen, Ihre Kaptive-Inhalte auf jedem Gerät mit einem modernen Webbrowser anzuzeigen. Dies ist eine hervorragende Option für Geräte, die den Kaptive Player nicht unterstützen, oder für Situationen, in denen Sie schnell eine Anzeige ohne zusätzliche Hardware einrichten möchten.

Sie können Kaptive Web unter [https://player.kaptive.app](https://player.kaptive.app) aufrufen. Um es mit Ihrem Kaptive-Konto zu verbinden:

<Steps>
    1. Öffnen Sie [https://player.kaptive.app](https://player.kaptive.app) auf Ihrem Gerät.
    2. Scannen Sie den QR-Code oder geben Sie den Code manuell auf [https://kaptive.app/verify](https://kaptive.app/verify) ein.
    3. Wählen Sie einen Namen für Ihre Kaptive Web-Instanz, um sie in Ihrem Konto zu identifizieren.
    4. Wählen Sie den Workspace aus, in den Sie sie hinzufügen möchten.
    5. Klicken Sie auf `Verify Device`.
 </Steps>

Sobald verbunden, erscheint der Player in Ihrem Konto unter dem ausgewählten Workspace, und Sie können mit der Veröffentlichung von Inhalten beginnen.

## Einschränkungen

Kaptive Web ist für Tests und kleinere Anwendungsfälle vorgesehen. Es bietet nicht das gleiche Maß an Leistung, Zuverlässigkeit und Sicherheit wie der Kaptive Player.

Kaptive Web hat im Vergleich zum Kaptive Player folgende Einschränkungen:
- Keine Unterstützung für Screenshots oder Remote-Geräteverwaltung.
- Die Leistung kann je nach verwendetem Gerät und Browser variieren.
- Keine Offline-Unterstützung, das Gerät muss mit dem Internet verbunden sein, um Inhalte anzuzeigen.
- Keine physischen Bildschirmsteuerungen wie Energieverwaltung oder Eingangshandhabung.
- Kein Kioskmodus, der Browser muss manuell so konfiguriert werden, dass er im Vollbildmodus läuft und die Benutzerinteraktion mit der Browser-Oberfläche verhindert.
