## How Alerts Work in Kaptive

Kaptive allows you to set up alerts that can be triggered by an administrator in the Kaptive Editor. When an alert is triggered, it overrides any default or scheduled content on the assigned Players and shows the alert content instead. This is useful for showing urgent messages or important announcements that need to be displayed immediately.
