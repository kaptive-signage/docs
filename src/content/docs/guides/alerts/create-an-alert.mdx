## What Is an Alert?

An Alert is a special type of Project. It uses the exact same Kaptive Editor, the same Content Elements, and the same Assign and Publish workflow as any other Project.

The difference is in what happens when you activate it. When an Alert is activated, it immediately overrides all content on its assigned Players: default assigned Projects and active Schedules are both suspended. The Alert plays until you deactivate it. When deactivated, every Player returns to the content it was showing before.

This makes Alerts suited for urgent messages, safety announcements, or any situation where content needs to appear on screens immediately, regardless of what is currently scheduled.

---

## Create an Alert

<Steps>
1. In Kaptive Manager, go to the Alerts section and click `New Alert`.
2. Enter a name and choose a resolution that matches your screens.
3. Click `Create`.
</Steps>

This opens the Kaptive Editor. The interface is identical to the Project editor: the same toolbar, the same left and right sidebars, the same canvas. Add Content Elements, design your Pages, and style them exactly as you would in any Project.

<Aside type="tip">Keep Alert content simple and immediately readable. Large text, high contrast, and a clear message work best for urgent situations where someone must absorb the content quickly.</Aside>

---

## Assign an Alert to Players

Assigning an Alert to Players registers those Players as targets for the Alert. The Alert does not appear on screen yet: it only becomes visible when you activate it.

<Steps>
1. In the Kaptive Editor, click `Assign` in the top-right corner.
2. Select the Players that should show this Alert when it is activated.
3. Click `Assign`.
</Steps>

You can assign the same Alert to as many Players as needed. Players that are not assigned to an Alert are not affected when that Alert is activated.

---

## Publish Updates to an Alert

After editing an Alert that is already assigned, click the orange `Publish` button to push the updated version to all assigned Players. The update takes effect the next time the Alert is activated.

<Aside type="note">If an Alert is currently active when you publish an update, assigned Players will show the updated content immediately.</Aside>

---

## Activate an Alert

Activating an Alert causes it to appear on all its assigned Players at once, overriding any content currently playing: whether that is a default assigned Project or an active Schedule.

To activate an Alert, click the `Activate Alert` button in the Alert editor or from the Alerts overview in Kaptive Manager.

Once active, the Alert continues playing on all assigned Players until you deactivate it. No other content plays on those Players while the Alert is active.

---

## Deactivate an Alert

When the situation is resolved, deactivate the Alert to return each Player to its normal content.

To deactivate an Alert, click the `Deactivate Alert` button in the Alert editor or from the Alerts overview in Kaptive Manager.

Each assigned Player immediately resumes the content it was showing before the Alert was activated: its default assigned Project, or the currently scheduled Project from its active Schedule.
