Kaptive Web allows you to display your Kaptive content on any device with a modern web browser. This is a great option for devices that do not support the Kaptive Player hardware or for situations where you want to quickly set up a display without additional hardware.

You can access Kaptive Web at [https://player.kaptive.app](https://player.kaptive.app). To connect it to your Kaptive Account:

<Steps>
    1. Open [https://player.kaptive.app](https://player.kaptive.app) on your device.
    2. Scan the QR code or enter the code manually at [https://kaptive.app/verify](https://kaptive.app/verify).
    3. Choose a name for your Kaptive Web instance to identify it in your account.
    4. Select the Workspace where you want to add it.
    5. Click `Verify Device`.
 </Steps>

Once connected, the Player appears in your account under the selected Workspace, and you can start publishing content to it.

## Limitations

Kaptive Web is intended for testing and small-scale use cases. It does not provide the same level of performance, reliability, and security as the Kaptive Player hardware.

Kaptive Web has the following limitations compared to the Kaptive Player:
- No support for screenshots or remote device management.
- Performance may vary based on the device and browser used.
- No offline support, the device must be connected to the internet to display content.
- No physical screen controls, such as power management or input handling.
- No kiosk mode, the browser has to be configured manually to run in full-screen mode and prevent user interaction with the browser UI.
