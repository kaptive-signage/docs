description: Learn how to use Kaptive on iOS devices.

The Kaptive iOS app is available on demand. [Contact us](https://kaptive.ch/contact) if you are interested in running interactive applications on iOS devices. The app is designed to run Kaptive content on iPhones and iPads, allowing you to turn any iOS device into an interactive digital signage display.
