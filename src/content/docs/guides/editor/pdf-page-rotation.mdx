title: Auto-rotate PDF pages
description: Automatically scroll through the pages of a PDF at an interval you set.
---

A PDF added to your project can automatically scroll through its pages at an interval you set, so multi-page documents play on their own without any interaction. Select the PDF element, then set the page rotation interval in the element properties pane. Each page stays on screen for the chosen duration before advancing to the next, looping back to the first page once it reaches the end.
