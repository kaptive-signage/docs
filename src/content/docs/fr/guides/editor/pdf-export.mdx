Exportez n'importe quel projet en PDF pour le partager hors ligne, l'imprimer ou le transmettre pour relecture. Ouvrez les options d'export du projet et choisissez PDF : chaque page de votre projet devient une page du fichier. L'export conserve votre mise en page et votre contenu exactement comme conçus.
