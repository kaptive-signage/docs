Importez vos propres polices dans votre workspace et utilisez-les dans n'importe quel projet, pour que votre contenu corresponde toujours à votre identité de marque. Ouvrez les paramètres de polices de votre workspace et importez vos fichiers de police. Une fois importées, vos polices personnalisées apparaissent aux côtés des polices intégrées dans le sélecteur de polices de l'éditeur, prêtes à être utilisées dans tous les projets du workspace.
