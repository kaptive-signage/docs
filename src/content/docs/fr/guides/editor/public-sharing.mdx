Publiez n'importe quel projet sur le web pour le partager au-delà de vos écrans. Ouvrez les options de partage de votre projet, puis activez l'accès public pour générer un lien public que tout le monde peut ouvrir dans son navigateur. Vous pouvez aussi copier le code d'intégration pour insérer le projet directement dans votre propre site web sous forme d'iframe interactive. Les deux restent synchronisés avec votre projet : chaque modification que vous publiez apparaît instantanément partout où il est partagé.
