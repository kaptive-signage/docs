Le zoom du canvas est une fonctionnalité simple qui vous permet de zoomer sur le canvas de votre projet pour une précision au pixel près pendant la création. Pour zoomer sur votre canvas, maintenez `Ctrl` (ou `Cmd` sur Mac) et faites défiler vers le haut avec la molette de votre souris ou votre trackpad. Pour dézoomer, maintenez `Ctrl` (ou `Cmd` sur Mac) et faites défiler vers le bas.

Vous pouvez également utiliser les commandes de zoom en bas de l'éditeur. Choisissez l'un des niveaux de zoom prédéfinis ou ajustez la page à votre écran pour une vue complète de votre projet. Le niveau de zoom est affiché en pourcentage, ce qui vous permet de voir facilement à quel point vous avez zoomé ou dézoomé.
