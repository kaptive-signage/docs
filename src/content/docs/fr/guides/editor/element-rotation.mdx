N'importe quel élément de contenu peut être pivoté dans l'éditeur pour plus de liberté de mise en page et de créativité. Pour faire pivoter un élément, sélectionnez-le et utilisez le champ de rotation dans le panneau des propriétés de l'élément. Vous pouvez saisir un angle de rotation précis ou faire glisser le champ de rotation pour faire pivoter l'élément librement.
