Le Kaptive Player est un appareil matériel dédié fonctionnant sous Kaptive OS, conçu pour offrir un moyen fiable et sécurisé d'afficher vos Projets Kaptive sur n'importe quel écran, vidéoprojecteur ou mur LED équipé d'un port HDMI.

Le Kaptive Player est recommandé pour les déploiements commerciaux et les cas d'utilisation critiques, car il offre des performances, une sécurité et des fonctionnalités renforcées.

## Commander un Kaptive Player

Pour commander un Kaptive Player, veuillez [nous contacter](https://kaptive.ch/contact).

## Configurer votre Kaptive Player

Lorsque vous recevez votre Kaptive Player, connectez-le simplement à un écran via le port HDMI et allumez-le. Le Player démarre automatiquement et affiche un QR code à l'écran.

Si vous souhaitez ajouter de l'Interactivité tactile, connectez un écran tactile compatible au Player via le port USB. Le Player détecte automatiquement l'écran tactile et active la saisie tactile.

## Connecter votre Kaptive Player à internet

Le Kaptive Player peut se connecter à internet via Ethernet ou Wi-Fi. Pour de meilleures performances et une meilleure fiabilité, nous recommandons d'utiliser une connexion Ethernet filaire. Cependant, si Ethernet n'est pas disponible, vous pouvez vous connecter en Wi-Fi en suivant les instructions à l'écran sur le Player. Sélectionnez simplement votre réseau Wi-Fi dans la liste, entrez le mot de passe, et le Player se connectera au réseau. Vous pouvez saisir le SSID et le mot de passe soit à l'aide d'un clavier et d'une souris connectés, soit à l'aide du clavier à l'écran avec un écran tactile.

## Connecter votre Kaptive Player à votre compte

Une fois le Player démarré, un QR code s'affiche à l'écran. Pour le relier à votre compte Kaptive :

<Steps>
    1. Scannez le QR code ou entrez le code manuellement sur [https://kaptive.app/verify](https://kaptive.app/verify).
    2. Choisissez un nom pour votre Player afin de l'identifier dans votre compte.
    3. Sélectionnez le Workspace dans lequel vous souhaitez ajouter le Player.
    4. Cliquez sur `Verify Device`.
 </Steps>

Une fois le Player connecté, il apparaît dans votre compte sous le Workspace sélectionné, et vous pouvez commencer à publier du Contenu dessus.

## Cas d'utilisation recommandés

Le Kaptive Player est le moyen le plus fiable et sécurisé de diffuser des Projets Kaptive sur des écrans.

Pour les cas d'utilisation suivants, le Kaptive Player physique est obligatoire :

- Captures d'écran et gestion à distance des appareils
- Mode kiosque natif pour les installations sécurisées dans les espaces publics
- Support natif des écrans tactiles pour les applications interactives
- Support hors ligne pour les environnements avec une connectivité internet peu fiable ou inexistante
- Contrôles physiques de l'écran, tels que la gestion de l'alimentation et des entrées
- Alertes avec contrôles physiques de l'écran
