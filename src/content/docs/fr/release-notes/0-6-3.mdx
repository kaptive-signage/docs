## Fonctionnalités

- Retour automatique à la page d'accueil après une période d'inactivité. Vous pouvez définir après combien de temps l'écran revient automatiquement à la page d'accueil, pour une meilleure expérience utilisateur et pour que les contenus importants restent toujours visibles.

- Sélection de plusieurs pages pour les actions groupées. Vous pouvez désormais sélectionner plusieurs pages à la fois pour leur appliquer une action groupée, ce qui simplifie la gestion du contenu et vous fait gagner du temps.
