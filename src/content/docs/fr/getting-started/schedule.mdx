## Comment fonctionne la planification sur les Kaptive Players

Vous avez probablement déjà lu le chapitre sur l'Assignation de Projets. La planification est l'autre moyen de diffuser du Contenu sur vos Kaptive Players. Au lieu d'assigner un seul Projet à un Player, vous pouvez planifier plusieurs Projets dans un Schedule. Un Schedule est une collection de Projets diffusés sur un Player à des horaires précis.

Lors de la création d'un Schedule, vous pouvez sélectionner les Projets à inclure et définir quand ils doivent être diffusés sur les Players assignés.

![Planifier des projets](../../../../assets/getting-started/schedule/schedule.png)

En cliquant sur un Projet dans le Schedule, vous pouvez sélectionner la plage horaire pendant laquelle le Projet doit être diffusé et configurer son intervalle de répétition. La répétition ne peut être définie que lorsqu'aucun autre Projet planifié ne chevauche dans le futur.

![Modifier le schedule](../../../../assets/getting-started/schedule/edit-schedule.png)

Vous pouvez ajouter autant de Projets que vous le souhaitez à un Schedule, mais ils ne peuvent pas se chevaucher dans le temps.

## Assigner un Schedule à un Player

Après avoir créé un Schedule, vous pouvez l'assigner à un Player en cliquant sur le bouton `Assign` dans l'éditeur de Schedule. Lorsqu'un Schedule est assigné à un Player, le Player diffuse les Projets du Schedule selon les plages horaires et les paramètres de répétition définis.

Lorsqu'un Schedule est assigné à un Player mais qu'aucun Projet n'est planifié au moment actuel, le Player affiche le Projet par défaut qui lui est assigné. Cela vous permet d'avoir un Contenu de repli lorsqu'aucun Projet planifié n'est actif. Le Contenu par défaut est configuré en assignant un Projet au Player.

![Assignation du schedule](../../../../assets/getting-started/schedule/assign-schedule.png)

## Publier les mises à jour de votre Schedule

Lorsque vous modifiez un Schedule, vous devez publier les modifications pour qu'elles prennent effet sur les Players assignés. Pour publier les modifications, cliquez simplement sur le bouton orange `Publish` dans l'éditeur de Schedule. Cela met à jour le Schedule sur tous les Players auxquels ce Schedule est actuellement assigné.
