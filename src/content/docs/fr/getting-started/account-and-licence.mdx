## À propos de votre compte

Pour commencer avec Kaptive, vous devez créer un compte personnel gratuit et vérifier votre adresse e-mail.

Vous pouvez également vous authentifier avec Google ou GitHub pour un processus d'inscription plus rapide.

Une fois votre compte configuré, il vous sera demandé de créer un Workspace dans lequel vous pourrez gérer vos Projets et vos Players. Par défaut, vous disposerez d'un Workspace gratuit avec accès aux fonctionnalités de base.

## Créer un nouveau compte

<Steps>

    1. Rendez-vous sur [https://kaptive.app](https://kaptive.app).
    2. Cliquez sur `Sign up`.
    3. Vous pouvez également cliquer sur `Sign in with Google` ou `Sign in with GitHub` pour vous inscrire via un compte social.
    4. Suivez les instructions pour créer votre compte.

</Steps>

## Choisir une Licence

Kaptive propose différentes Licences adaptées à vos besoins, y compris une offre gratuite avec les fonctionnalités de base et des offres payantes avec des fonctionnalités avancées. Pour en savoir plus sur nos options de Licence, consultez notre site web à l'adresse [https://kaptive.ch/features](https://kaptive.ch/features) ou [contactez-nous](mailto:info@kaptive.ch).
