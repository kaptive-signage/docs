## Comment fonctionne l'Assignation de votre Projet à un Kaptive Player

Dès que vous avez créé votre Projet, vous voudrez l'assigner à vos Kaptive Players. Cette étape s'appelle l'Assignation.

En cliquant sur le bouton `Assign` en haut à droite dans le Kaptive Editor, vous pourrez sélectionner les Players auxquels vous souhaitez assigner votre Projet. Une fois les Players sélectionnés, cliquez sur `Assign` pour lancer la diffusion sur les Kaptive Players.

![Assigner un projet aux Players](../../../../assets/getting-started/assign/assign-project.png)

Le Projet assigné commence à être diffusé immédiatement sur les Kaptive Players sélectionnés. Vous pouvez assigner le même Projet à plusieurs Players. Le Projet assigné sera le Contenu par défaut diffusé sur les Players assignés.

Découvrez dans le chapitre suivant comment fonctionne la planification de Projets sur Kaptive.

## Publier les mises à jour de votre Projet

Il arrive que vous souhaitiez mettre à jour votre Projet après l'avoir assigné à vos Players. Par exemple, vous pourriez vouloir modifier du Contenu ou corriger une faute. Dans ce cas, cliquez simplement sur le bouton orange `Publish` situé juste à côté du bouton `Assign` dans le Kaptive Editor. Cela publiera la dernière version de votre Projet sur tous les Players qui lui sont actuellement assignés.

C'est particulièrement important lorsque vous avez planifié votre Projet dans un Schedule. Pour que le Schedule affiche la dernière version de votre Projet, vous devez publier les modifications après avoir édité votre Projet. En savoir plus sur la planification dans le chapitre suivant.
