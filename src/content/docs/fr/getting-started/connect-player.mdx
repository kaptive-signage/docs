## Choisir votre type de player

Vous pouvez diffuser du contenu Kaptive en utilisant soit un Kaptive Player, soit Kaptive Web qui fonctionne dans n'importe quel navigateur. Le Kaptive Player offre une fiabilité et une sécurité renforcées. Certaines fonctionnalités, comme les captures d'écran du player, ne sont pas disponibles sur Kaptive Web.

Nous recommandons d'utiliser un Kaptive Player pour les déploiements commerciaux, tandis que Kaptive Web convient pour les tests et les cas d'utilisation à petite échelle.

Kaptive Web est accessible à l'adresse [https://player.kaptive.app](https://player.kaptive.app).

## Connecter un player à votre compte

Lors du premier démarrage d'un Kaptive Player ou lors de l'accès à Kaptive Web, vous serez invité à connecter le player à votre compte Kaptive.

![Écran de connexion du player](../../../../assets/getting-started/connect-player/code.png)

Pour connecter le player à votre compte :

<Steps>
    1. Scannez le QR code ou entrez le code manuellement sur [https://kaptive.app/verify](https://kaptive.app/verify).
    2. Choisissez un nom pour votre player afin de l'identifier dans votre compte.
    3. Sélectionnez le workspace dans lequel vous souhaitez ajouter le player.
    4. Cliquez sur `Verify Device`.
 </Steps>

Une fois le player connecté, il apparaît dans votre compte sous le workspace sélectionné, et vous pouvez commencer à publier du contenu dessus.
