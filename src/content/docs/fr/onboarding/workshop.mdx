## Le Kaptive Player

Le Kaptive Player est un petit appareil qui se connecte à votre écran et diffuse votre contenu. Il nécessite les connexions suivantes :

- Alimentation : l'alimentation électrique.
- Ethernet : la connexion réseau.
- HDMI : la sortie vidéo vers l'écran.
- RS232 : la connexion série utilisée pour contrôler l'écran, l'allumer ou l'éteindre et changer la source d'entrée.
- USB : la connexion pour la saisie tactile sur les écrans tactiles.

Ne débranchez jamais aucun câble du Kaptive Player. Déconnecter l'alimentation, l'Ethernet, le HDMI ou le RS232 envoie un message au service technique.

---

## L'écran

Kaptive contrôle l'écran via RS232. Lorsqu'une alerte est activée, Kaptive bascule automatiquement l'écran vers la bonne source HDMI. Les schedules peuvent allumer l'écran, changer la source d'entrée et commencer à afficher du contenu à une heure configurée.

Pour passer à une autre source comme un ordinateur portable, changer manuellement l'entrée de l'écran.

## Cas d'usages

Kaptive couvre trois catégories d'utilisation.

### Digital signage

Contenu passif affiché sur les écrans sans interaction utilisateur.

- Écrans d'information simples
- Horaires de trains et de bus
- Menus de cafétéria

### Applications interactives

Interfaces tactiles que les utilisateurs naviguent directement.

- Expositions muséales interactives
- Écrans d'orientation de bâtiment
- Présentations interactives
- Tableaux d'information interactifs : événements à venir, prochains départs, menus de cafétéria
- Applications basées sur API : tableaux de bord, visualisations de données, etc.

### Alertes

Contenu qui remplace instantanément tous les écrans lors de l'activation.

- Écrans d'information précis à la demande dans des emplacements choisis
- Instructions d'évacuation guidée
- Alarmes incendie
- Alarmes amok

## Rôles

- Editor : peut modifier les projets et schedules existants et publier les modifications.
- Manager : peut créer et gérer des projets et des schedules, et les assigner à des players.
- Admin : accès complet, y compris les alertes et la gestion des membres.

Consultez [Rôles](../../guides/general/roles) pour la référence complète.

---

## Démonstration rapide

1. Allumer l'écran via Kaptive.
2. Montrer le projet assigné par défaut en cours de diffusion sur l'écran.
3. Passer l'écran sur une autre source, comme un ordinateur portable.
4. Déclencher une alerte de test. Kaptive bascule automatiquement vers la bonne source et affiche le contenu de l'alerte.
5. Désactiver l'alerte. L'écran revient à son contenu précédent.
6. Éteindre l'écran via Kaptive.
