## How Scheduling on Kaptive Players Works

You probably already read the chapter on Project assignment. Scheduling is the other way to show content on your Kaptive Players. Instead of assigning one single Project to a Player, you can schedule several Projects in a Schedule. A Schedule is a collection of Projects that are shown on a Player at specific times.

When creating a Schedule, you can select which Projects you want to include in the Schedule and when they should be shown on the assigned Players.

![Schedule Projects](../../../assets/getting-started/schedule/schedule.png)

When clicking on a Project in the Schedule, you can select the time range when the Project should be shown and configure its repeating interval. The repetition can only be set when no other scheduled Projects are overlapping in the future.

![Edit Schedule](../../../assets/getting-started/schedule/edit-schedule.png)

You can add as many Projects to a Schedule as you want, but they cannot overlap in time.

## Assign a Schedule to a Player

After creating a Schedule, you can assign it to a Player by clicking the `Assign` button in the Schedule editor. When a Schedule is assigned to a Player, the Player shows the Projects in the Schedule according to the defined time ranges and repetition settings.

When a Schedule is assigned to a Player, but no Project is scheduled to be shown at the current time, the Player shows the default Project assigned to it. This allows you to have fallback content when no scheduled Projects are active. The default content is configured by assigning a Project to the Player.

![Schedule Assignment](../../../assets/getting-started/schedule/assign-schedule.png)

## Publish Updates of your Schedule

When you make changes to a Schedule, you need to publish the changes for them to take effect on the assigned Players. To publish the changes, simply click the orange `Publish` button in the Schedule editor. This updates the Schedule on all the Players that currently have this Schedule assigned to them.
