## What Is Interactivity?

The **Kaptive Editor** allows creating fully touch-native interfaces made for physical interaction with screens. You can add buttons, 3D models, scrollable PDFs, a lot of elements and widgets that allow to create an entire application for museums, building orientations, information screens or order screens.

Instead of having to implement an entire web application or native application to run a touchscreen, you can do it all using Kaptive.

![Add buttons for interactivity](../../../assets/getting-started/interactivity/kaptive_editor.png)

## Add Buttons

In the toolbar of the Kaptive Editor, you can choose to add a button to your project. In the properties of a button, you can choose which page to link. This allows you to create entire applications with multiple pages, transitions and interactions.

Do not forget to add back buttons on details pages, to be able to navigate correctly through your entire application.

## Add Transparency or Images to Button Backgrounds

To create more advanced interactive applications, you can make buttons transparent or add background images. This allows to you to easily create bento boxes, lists or create clickable schemas, plans or maps.
